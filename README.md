# আমার প্রথম বই (My First Book)

A free, offline, ad-free talking book for play/nursery kids. Tap a letter or picture and the book speaks it.

**What's inside**
- Bangla alphabet (vowels + consonants), English A–Z with Bangla meaning, Arabic letters, numbers 1–100
- Picture words: animals, birds, fruits, vegetables, flowers, vehicles, shapes, colours, body parts, days, seasons
- 13 rhymes, gojol and songs (original Bangla rhymes; public-domain English rhymes) with a music-box tune and highlighted lines
- "Name the picture" game with star rewards

## Build the APK (GitHub Actions)
1. Push this folder to a GitHub repository (branch `main`).
2. Open the **Actions** tab, then run **Build APK** (or just push).
3. Download the `amar-prothom-boi-apk` artifact and install the APK.

The workflow always installs the latest Capacitor, text-to-speech plugin and Actions.

## Voice
Uses the phone's built-in text-to-speech. For Bangla, install **Speech Services by Google** and download the Bengali voice (Settings > Language > Text-to-speech).
